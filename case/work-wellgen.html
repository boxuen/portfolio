WELLGEN 結核菌玻片掃描檢驗系統

整理 μ-Scan 結核菌玻片掃描檢驗系統的架構與元件功能，撰寫成技術文件。

專案概述

參與「115 年度 UNEXT 數位創新人才增能培育計畫」，負責 WELLGEN Tuberculosis 結核菌玻片掃描檢驗系統的技術文件。文件依操作流程說明各模組的 UI 元件、輸入輸出、流程圖及例外處理，作為系統開發、維護與交接的依據。

主要功能與內容

  • 依操作流程說明各模組
  • 涵蓋 UI 元件、輸入輸出、流程圖與例外處理
  • 中英雙語撰寫

我負責的部分

技術文件與流程圖

  1. 撰寫 TB（肺結核）、細胞學及硬體裝置三大模組的技術文件
  2. 繪製各模組的功能流程圖
  3. 整理系統操作流程、功能架構、程式碼位置及使用套件
