ASKY：AI 共同協作平台

可以量身打造專屬 Assistants bot 的協作平台，並支援數據儲存與分析。

專案概述

ASKY 是參與「2024 DIGI+ Talent 跨域數位人才加速躍升計畫」時完成的 AI 協作平台。使用者可以依照自己的需求建立專屬的聊天機器人（小助手），應用在教學輔助、行政自動化、客服回應等不同情境。

主要功能與內容

  • 打造可量身訂製的 Assistants bot 建立平台，支援多種應用情境
  • 平台支援數據儲存與分析，協助使用者追蹤互動成效
  • 提供簡易操作介面與模組化設定流程，降低使用門檻

我負責的部分

後端 API 與資料庫

  1. 使用 ASP.NET 開發後端 API
  2. 串接 ChatGPT API，讓使用者建立自己的 Assistants bot
  3. 設計專案所需的資料庫，包含商業數據分析資料庫
  4. 擔任計畫期末成果展的上台發表成員
